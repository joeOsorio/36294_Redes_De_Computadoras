# 📘 Redes de Computadoras

Repositorio académico de la materia **Redes de Computadoras** (etapa disciplinaria, obligatoria) de la carrera de **Ingeniero en Computación**, UABC.

## 🎯 Propósito
Conocer los principios fundamentales de redes de cómputo y transmisión de datos que permitan resolver problemas de interconexión entre distintas organizaciones, compartiendo información y recursos tecnológicos.

## 🎓 Competencia
Definir los requerimientos de procesamiento y comunicación de información mediante la integración de estándares de diseño e implementación de redes de computadoras, de manera responsable y honesta.

## 🗂️ Unidades del curso
1. **Redes de computadoras** — Conceptos y usos, arquitectura de protocolos, modelo de referencia OSI, organizaciones y estándares (IEEE, ISO, ANSI, IETF, ITU)
2. **Capa física** — Topologías de red (bus, anillo, estrella, inalámbrica), medios de comunicación (coaxial, UTP/STP, fibra óptica, inalámbricos)
3. **Capa de enlace** — Técnicas de comunicación, conmutación de paquetes, Ethernet, redes inalámbricas, codificación (Manchester, 4B/5B, NRZ), CSMA/CD, CSMA/CA
4. **Direccionamiento y capas superiores** — IPv4/IPv6, máscaras de red, TCP/UDP/SCTP, servicios TCP/IP (correo, DNS, FTP, HTTP, streaming)

## 🧪 Prácticas de taller
Investigación de estándares y organizaciones, ejercicios del modelo OSI, ponchado de cable UTP (ANSI/TIA 568), configuración de LAN en estrella, análisis de tráfico 802.11, análisis de tramas Ethernet, análisis de protocolos ICMP/ARP e implementación de un servicio Web (HTTP).

## 🏗️ Evidencia de desempeño
Reporte técnico de recomendación que describe los requerimientos de interconexión de una organización (introducción, metodología, resultados, conclusiones y referencias).

## 🛠️ Tecnologías
- Cable UTP, conectores RJ-45, dispositivos de interconexión
- Analizadores de protocolos (ej. Wireshark)
- Herramientas de red del sistema operativo, servidor HTTP
- Control de versiones: Git y GitHub
